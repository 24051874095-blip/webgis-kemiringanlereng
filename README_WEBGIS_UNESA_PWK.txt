WEBGIS KEMIRINGAN LERENG KABUPATEN MAGELANG

Cara menjalankan:
1. Ekstrak seluruh folder ZIP.
2. Buka folder qgis2web_2026_10_21-17_07_10_819338.
3. Buka index.html menggunakan Chrome/Edge.
4. Jangan pisahkan index.html dari folder resources, layers, styles, dan file pendukung lainnya.

Catatan penting:
- Peta dan layer berasal dari hasil ekspor qgis2web yang kamu kirim.
- style.css mengatur layout, sidebar, menu, responsivitas, dan kontrol peta.
- Legenda memakai simbol PNG hasil ekspor QGIS; teks kelas perlu disesuaikan dengan klasifikasi asli di QGIS.
- Logo UNESA dan PWK pada paket ini merupakan ilustrasi sementara, bukan lambang resmi. Ganti images/logo-unesa.svg dan images/logo-pwk.svg dengan file logo resmi dari kampus/prodi jika tersedia.
- WebGIS dibuka secara lokal; untuk publikasi online, unggah seluruh isi folder ke hosting statis.
